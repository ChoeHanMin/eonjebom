# 언제봄

친구들과 **시간표 코드**를 주고받아서 언제 함께 시간이 되는지 색으로 보여 주고 추천해 주는 웹앱이에요.
[when2meet](https://www.when2meet.com/)처럼 가입 없이 쓰고, **서버도 없어요.** HTML 파일 하나가 브라우저 안에서 전부 처리해요.

- **3단계 색상**: 🟩 한가함 · 🟨 잘 모르겠음 · 🟥 바쁨 (+ 미입력 회색)
- **엑셀 같은 시간표**: 30분 = 1칸, 하루 48칸. 색을 고르고 드래그하면 그 범위가 한 번에 칠해져요 (마우스·손가락 모두).
  지우개는 따로 없고, **고른 색과 같은 색 칸을 한 번 더 누르거나 끌면 지워져요.** (날짜별 일정에서는 직접 칠한 칸만 지워지고 기본 시간표·캘린더 색으로 돌아가요)
- **캘린더 파일 가져오기**: 구글·삼성·애플·네이버 캘린더에서 내보낸 `.ics` 파일로 바쁜 시간을 자동으로 칠해요.
- **이미지로 저장**: 시간표를 PNG 그림으로 저장해요. 휴대폰에서는 공유 창의 "이미지 저장"으로 갤러리에 들어가요.
- **벚꽃 배경**: 한강 벚꽃길 그림 위로 꽃잎이 흩날려요. 꽃잎은 내용 뒤에 그려서 글씨를 가리지 않고, 기기의 '동작 줄이기' 설정이 켜져 있으면 멈춰요.

## 쓰는 방법

1. 이름만 적고 **시작하기**.
2. **기본 시간표**에 매주 반복되는 일정(수업, 알바)을 칠하거나, **캘린더 가져오기**로 `.ics` 파일을 넣어요.
   이번 주만 다른 칸은 **날짜별 일정**에서 칠해요.
3. 위쪽 **내 시간표 보내기**를 누르면 시간표 코드가 담긴 메시지가 복사돼요(휴대폰은 공유 창). 카톡으로 친구에게 보내요.
4. 친구도 언제봄을 열어 자기 시간표를 칠하고 코드를 보내 주면, **언제봄** 탭의 "친구 코드 추가"에 메시지를 통째로 붙여 넣어요.
   둘 다 되는 시간이 색으로 보이고, 좋은 시간부터 추천해 줘요. 여러 명을 골라 모두 되는 시간도 찾을 수 있어요.
   **"모두 함께 / 나 / 친구 이름"** 버튼으로 각자의 시간표만 따로 볼 수도 있어요. (친구 코드를 추가하면 그 친구 시간표가 먼저 보여요)

### 메인 화면

- 좌상단 **'언제봄'** 글자나 메뉴의 **'🏠 홈 화면으로 가기'**를 누르면 "메인 화면으로 가시겠습니까?" 확인 창이 뜨고, **"응 갈거야"**를 눌러야 이동해요.
- 메인 화면으로 가도 시간표는 지워지지 않아요. "○○ 님 시간표로 돌아가기"로 바로 돌아올 수 있고,
  **새 이름으로 다시 시작**할 때만 한 번 더 확인한 뒤 지금 시간표를 지워요.
- 메인 화면 아래 **'개발자'** 버튼으로 만든 사람 소개를 볼 수 있어요.

### 시간표 코드

서버가 없으므로 시간표를 코드 안에 통째로 담아 주고받아요. (`EB2.`로 시작, 보통 50~100자)

- 담기는 것: 이름, 매주 기본 시간표, **이번 주 월요일부터 3주간의 실제 일정**(캘린더·날짜별 수정 반영). 일정 제목은 담기지 않아요.
- 받은 쪽은 3주 안의 날짜는 실제 일정으로, 그 뒤는 기본 시간표로 봐요.
- 코드는 보내는 순간의 시간표예요. 시간표를 바꾸면 **새 코드를 다시 보내야** 친구 쪽에 반영돼요. 같은 사람의 새 코드를 붙여 넣으면 이전 것이 바뀌어요.
- 3주 중 기본 시간표와 같은 날은 1비트 표시만 넣고, 다른 날(캘린더·날짜별 수정)만 따로 담아요.
  칸 값은 연속된 같은 값을 1바이트로 묶어요(`src/share-code.js`). 그래서 칠한 모양이 단순할수록 코드가 짧아요.
- 보내는 메시지에는 코드가 든 링크 하나만 들어가요. 링크를 "친구 코드 추가"에 붙여 넣어도 돼요.
- 예전 형식(`EB1.`) 코드도 그대로 읽을 수 있어요.

### 카카오톡 등 앱 안에서 열었을 때

카톡으로 받은 링크는 카톡 안의 브라우저에서 열리는데, 이 브라우저는 크롬·사파리와 저장 공간이 따로라서
거기서 만든 시간표는 나중에 크롬·사파리에서 보이지 않아요. 그래서 앱 안에서 열리면 (`public/js/inapp.js`)

- **카카오톡**: 카톡의 외부 브라우저 열기 기능(`kakaotalk://web/openExternal`)으로 크롬·사파리에 자동으로 넘겨요.
- **라인**: `openExternalBrowser=1` 로 자동으로 넘겨요.
- **그 밖의 앱**(인스타그램, 네이버 앱 등): 안드로이드는 크롬으로 넘기기를 시도하고, 아이폰은 안내만 보여 줘요.
- 넘어가지 않으면 "크롬·사파리로 열기" 버튼, 메뉴에서 여는 방법, 링크 복사, "그냥 여기서 쓸게요"가 있는 안내 화면이 남아요.
- 친구 시간표 코드는 `?c=코드` 로 바꿔 함께 넘겨서, 외부 브라우저에서도 바로 비교 화면이 떠요.

### 데이터 저장

- 모든 데이터는 **그 브라우저(localStorage)에만** 저장돼요. 다른 사람이나 서버로 보내지는 건 내가 직접 보낸 시간표 코드뿐이에요.
- 다른 기기로 옮길 때는 **내 정보 › 내 시간표 코드**를 복사해서, 새 기기의 첫 화면 › "다른 기기에서 쓰던 시간표가 있나요?"에 붙여 넣어요. 기본 시간표가 옮겨지고, 캘린더 파일은 새 기기에서 다시 가져와요.
- 브라우저 기록(사이트 데이터)을 지우면 시간표도 지워져요.

### 한 칸의 색이 정해지는 순서

1. 그 날짜에 직접 칠한 값 → 2. 캘린더 파일의 일정(캘린더마다 바쁨/잘 모르겠음 선택) → 3. 매주 기본 시간표 → 4. 미입력(회색)

여러 사람을 비교할 때는 칸마다 **가장 바쁜 사람의 상태**를 쓰고, 한 명이라도 미입력이면 회색이에요.

## 개발

```bash
npm install
npm test          # 일정 계산, .ics 해석, 시간표 코드, 저장소 테스트
npm run build     # dist/index.html 하나로 만들기 (그대로 열거나 아무 곳에나 올리면 됨)
npm run dev       # 파일이 바뀔 때마다 다시 만들기
```

`npm run build` 는 두 파일을 만들어요.

- `dist/index.html`: 완성된 페이지. 더블클릭해서 열어도 되고, GitHub Pages·Netlify 등 정적 호스팅에 그대로 올려도 돼요.
  호스팅하면 보내는 메시지에 `…#c=코드` 링크도 붙어서, 친구가 링크만 눌러도 코드가 자동으로 들어가요.
- `dist/artifact.html`: claude.ai 미리보기(Artifact)용. `<html>`/`<head>` 없이 내용만 담겨 있어요.

### GitHub Pages로 올리기

`main`에 올라가면 GitHub Actions가 테스트와 빌드를 하고, **저장소가 공개(public)일 때만** GitHub Pages에 배포해요.
무료 계정은 비공개 저장소에서 Pages를 쓸 수 없어요. 공개로 바꾼 뒤 저장소 › Settings › Pages › Source를 **GitHub Actions**로 한 번 정해 주면,
주소는 `https://choehanmin.github.io/eonjebom/` 이 돼요.

## 구조

```
eonjebom/
├─ src/                    # 화면과 무관한 핵심 로직 (Node 테스트 가능)
│  ├─ availability.js      # 일정 합치기·비교·추천
│  ├─ time.js              # KST 날짜 / 30분 칸 계산
│  ├─ ics.js               # .ics 해석 (반복 일정, 예외, 시간대) — ical.js 사용
│  ├─ share-code.js        # 시간표 ↔ 시간표 코드
│  └─ store.js             # 브라우저 저장소(localStorage)에 데이터 보관·계산
├─ public/
│  ├─ style.css
│  ├─ assets/background.webp  # 배경 그림 (빌드할 때 HTML 안에 넣음)
│  └─ js/                  # main.js(화면), grid.js(격자·드래그), export.js(이미지 저장), petals.js(꽃잎), inapp.js, levels.js
├─ scripts/build.mjs       # esbuild 로 HTML 파일 하나에 묶기
└─ test/
```

## 서버를 없애면서 뺀 기능

- 8자리 짧은 코드 (시간표를 보관할 서버가 필요) → 시간표를 담은 긴 코드로 대체
- iCal 주소 자동 동기화 (대부분의 캘린더 주소는 브라우저에서 직접 읽을 수 없게 막혀 있음) → `.ics` 파일 가져오기로 대체
- 구글 캘린더 로그인 연동 → 나중에 구글 OAuth 클라이언트 ID를 만들면 서버 없이도 다시 넣을 수 있어요
- 수정 링크, 90일 자동 삭제, 코드 조회 횟수 제한 (서버 전용)
